All clients talk to the same daemon and see the same projects, agents and permission
requests, live. Use several at once.

| Client  | Platforms | Distribution |
| ------- | --------- | ------------ |
| Desktop | Windows x64, macOS (arm64, x64), Linux x64 | GitHub releases |
| Web     | Any modern browser | Served by the daemon |
| Android | arm64, Android 10+ | APK on GitHub releases |
| iOS     | Not released | Build from source |
| CLI     | Linux, macOS, Windows | Installed with the daemon |
