The flake lives in `deploy/nix` of the repository. It provides packages for x86_64 and
aarch64 Linux and macOS, and a NixOS module.

## NixOS module

```nix title="flake.nix"
{
  inputs.nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
  inputs.fde.url = "github:frogg-app/fde?dir=deploy/nix";

  outputs = { nixpkgs, fde, ... }: {
    nixosConfigurations.build-box = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        fde.nixosModules.default
        {
          services.fde = {
            enable = true;
            openFirewall = true;
            hostnames = [ "build-box.lan" ];
            environment.FDE_LOG_LEVEL = "debug";
            settings.daemon.mcp.injectIntoAgents = true;
          };
        }
      ];
    };
  };
}
```

## Options

| Option                            | Default | Meaning |
| --------------------------------- | ------- | ------- |
| `services.fde.enable`             | `false` | Run the daemon as a systemd service |
| `services.fde.package`            | the flake's package | Package to run |
| `services.fde.user`, `group`      | `fde`   | Service account |
| `services.fde.dataDir`            | `/var/lib/fde` (or `/home/<user>/.fde` for another user) | `FDE_HOME` |
| `services.fde.port`               | `9999`  | Listen port |
| `services.fde.listenAddress`      | `0.0.0.0` | Listen address |
| `services.fde.openFirewall`       | `false` | Open the port in the firewall |
| `services.fde.hostnames`          | `[]`    | Allowed hostnames, or `true` |
| `services.fde.relay.enable`       | `false` | Connect to a relay (`relay.host`, `relay.port` (443), `relay.useTls`, `relay.publicUseTls`) |
| `services.fde.inheritUserEnvironment` | `true` when `user` is not `fde` | Give the service the user's environment, so agent CLIs and logins are found |
| `services.fde.environment`        | `{}`    | Extra environment variables |
| `services.fde.settings`           | `{}`    | Written to `config.json` on every start |

:::caution
`settings` replaces `config.json` each time the service starts. Changes made with the CLI
or the app are lost on restart. Either manage configuration entirely in Nix, or leave
`settings` empty.
:::

## Running as your own user

Agents need their CLIs and logins. The simplest setup runs the service as the user who has
them:

```nix
services.fde = {
  enable = true;
  user = "alice";
  group = "users";
};
```

With `user` set, `dataDir` defaults to `/home/alice/.fde` and the service inherits that
user's environment.

## Package only

```sh
nix build "github:frogg-app/fde?dir=deploy/nix"
./result/bin/fde --version
```

The package installs `fde` and `fde-server`.

## Dependency hash

`npmDepsHash` is read from `deploy/nix/npm-deps.hash`. If your nixpkgs produces a different
hash for the same lockfile, override it:

```nix
fde.packages.x86_64-linux.default.override { npmDepsHash = "sha256-..."; }
```

For branded daemons, see [Nix for custom brands](/docs/fork-and-rebrand/other-distributions/#nix).
