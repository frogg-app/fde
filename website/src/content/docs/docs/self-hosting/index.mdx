The daemon is the part of FDE that does the work. It runs agents, stores history and serves
every client. You host it: on your workstation, a build server, a VM or a container.

| Default         | Value |
| --------------- | ----- |
| Port            | `9999` on all interfaces |
| State           | `~/.fde` (`FDE_HOME`) |
| Config          | `~/.fde/config.json` |
| Log             | `~/.fde/daemon.log` |
| Install root    | `~/.local/share/fde` (`install.sh`) |
| Service         | `fde-daemon` (systemd user), `app.frogg.fde-daemon` (launchd) |
