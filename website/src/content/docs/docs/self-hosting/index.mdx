The daemon is the part of Frogg that does the work. It runs agents, stores history and serves
every client. You host it: on your workstation, a build server, a VM or a container.

| Default         | Value |
| --------------- | ----- |
| Port            | `9999` on all interfaces |
| State           | `~/.frogg` (`FROGG_HOME`) |
| Config          | `~/.frogg/config.json` |
| Log             | `~/.frogg/daemon.log` |
| Install root    | `~/.local/share/frogg` (`install.sh`) |
| Service         | `frogg-daemon` (systemd user), `app.frogg.frogg-daemon` (launchd) |
